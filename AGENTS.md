## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Code Style
- Write code only. Do not add comments unless I explicitly ask for them.
- Do not add docstrings or explanatory comments to any code you generate or edit.
- Do not remove comments that already exist in the code.
- Make the code self-explanatory through clear variable and function names instead of comments.
